# PedROAM 训练过程、结果与直接测试

更新日期：2026-10-27。本文区分实验历史与最终使用的模型；所有误差单位均为米。

## 最终采用的模型

最终模型是 **仅使用 0421-AM 前 80% 从头训练的三特征 HybridShareNet，第 30 轮**。
没有加载官方或本地已有模型作为训练初值，归一化统计量也只从训练段计算。
测试脚本固定加载这个检查点，不会继续训练或根据测试结果重新挑选检查点。


## 数据与训练方法

输入来自 `/home/maxson/data/PedROAM/recordings/` 中的手机 RINEX 观测及广播星历。
先做等权 WLS，缓存初始位置、卫星信息和残差。每颗卫星的特征顺序是：

1. C/N0，沿用原实现的 `int8` 量化。
2. 卫星仰角，单位 rad。
3. 初始 WLS 伪距残差，单位 m。

网络为 `3 → 64 → 128 → 64 → 2` 的共享 MLP，输出观测权重和非负伪距修正量。
将输出送入可微 WLS 再定位，用预测位置与参考位置的水平距离进行反向传播。
每次求解都恢复固定的 GNSS-only 初始位置，不沿用上一次学习后的解。

参考按 UTC 最近邻匹配，容差 0.25 秒，要求 `gt_valid` 和经纬度有效。损失及评分
统一采用 WGS84 经纬度零高度投影到 ENU 的水平距离，不使用参考高度、姿态或车载杆臂。
输入仍保留原来的残差向量范数不超过 500 m 筛选；不按真实定位误差丢弃困难样本。

## 实验过程

| 阶段 | 训练方式与数据 | 选模方式 | 当次测试范围与结果 |
| --- | --- | --- | --- |
| 首次微调 | 官方三特征权重；0421-AM、0422-AM1、0422-PM，15,403 个有效历元 | 8 轮；0421-PM、0422-AM2 验证，选第 8 轮 | 0423-AM/PM 共同历元 RMSE 30.71 |
| 三场次从头训练 | 相同三个训练场次，全部随机初始化；训练集重新计算归一化 | 最多 30 轮；连续 6 轮验证无改善，实际 7 轮，选第 1 轮 | 0423-AM/PM 共同历元 RMSE 32.19 |
| **最终单场次训练** | **仅 0421-AM 前 80%，随机初始化** | **固定 30 轮，使用最后一轮；不设验证集** | 后 20% RMSE **32.88**；其他 6 场次 RMSE **33.38** |

前两次与最终模型的训练数据、学习率、训练预算或测试范围不同，不能将全部指标差异
归因于初始化。尤其前两次模型见过 0421-AM 全段，不作为最终后 20% 测试的独立对照。

## 最终 80/20 时间划分

P01、P02 的起始时间相差约 13 秒。为避免逐手机单独按比例切分造成跨手机时间重叠，
先将两路原始历元按 UTC 合并排序，再统一按 80%/20% 切分。
切分先于 GNSS 输入筛选及参考有效性筛选；训练段内部才随机打乱样本顺序。

边界为北京时间 **2026-04-21 12:35:30.040730**；边界及之后归测试集。
参考标签也在最近邻匹配前按同一边界分开。

| 手机 | 原始训练历元 | 有效训练样本 | 原始测试历元 | 有效参考测试历元 |
| --- | ---: | ---: | ---: | ---: |
| P01 | 2,985 | 2,951 | 755 | 716 |
| P02 | 2,999 | 2,946 | 741 | 735 |
| 合计 | **5,984** | **5,897** | **1,496** | **1,451** |

原始历元总数 7,480，整体精确为 80%/20%。归一化来自训练段的 **134,127 条卫星观测**。

| 参数 | 最终设置 |
| --- | --- |
| 初始化 | PyTorch 默认随机初始化；种子 20261027 |

| 设备 / 精度 | CPU / float64 |
| 优化器 / 学习率 | Adam / 0.001 |

| 训练轮数 | 固定 30；每轮使用全部 5,897 个有效训练样本 |
| 选模 | 第 30 轮；不早停、不使用测试误差选模 |

## 一条命令直接测试

当前机器已具备环境、数据、缓存和检查点。在仓库根目录运行：

```bash
cd /home/maxson/code/TDL-GNSS
bash pedroam/test_model.sh
```

脚本自动使用 `.venv-pedroam/bin/python`，默认同时评估后 20% 和其他 6 场次，分开汇总。
**默认输出到代码仓库的 `pedroam/results/test_<UTC时间>/`**，每次创建新目录。

如果希望保存到数据集 `/home/maxson/data/PedROAM/results/`：

```bash
bash pedroam/test_model.sh --output-root /home/maxson/data/PedROAM/results
```

只测试其他 6 个场次：

```bash
bash pedroam/test_model.sh --scope other-sessions
```

只测试 0421-AM 后 20%：

```bash
bash pedroam/test_model.sh --scope heldout-tail
```

其他实用选项：

```bash
# 指定新的结果目录名；同名已存在时拒绝覆盖
bash pedroam/test_model.sh --run-name my_test

# 强制从原始 RINEX 重新计算 GNSS 缓存，耗时更长
bash pedroam/test_model.sh --rebuild-cache

# 不加载官方模型，仅比较本地模型和 WLS
bash pedroam/test_model.sh --no-official

# 查看全部参数
bash pedroam/test_model.sh --help
```

若移动项目或数据，使用 `--dataset`、`--cache-root`、`--training-run`、`--baseline-weights`
覆盖路径；也可用 `TDL_PYTHON=/absolute/path/to/python` 指定已安装所需依赖的解释器。
`--training-run` 应包含本次时间切分实验的 `config.json`、`selection.json`、`final.pth`。
这些生成文件未纳入 Git，单独克隆源码不能自动获得本地训练权重和私有数据。

已有缓存会校验输入观测、星历及缓存本体的哈希。缓存不存在时自动从 RINEX 生成；
缓存缺少记录或输入已变化时，可用 `--rebuild-cache` 重建。只加载可信的本机 pickle 缓存。

## 结果文件

| 文件 | 内容 |
| --- | --- |
| `REPORT.md` | 本次两组测试的整体结果 |
| **`mean.csv`** | 整体、逐场次、逐手机的 mean 对照表 |
| `summary.csv` | mean、median、P95、RMSE、历元数、可用率的完整指标 |
| `overall.csv` | 后 20% 和其他场次分别汇总的指标 |
| `per_session.csv` / `per_phone.csv` | 逐场次 / 逐手机指标 |
| `predictions_model/` | 本地模型的经纬度、成功标记、失败原因与校验文件 |
| `predictions_official/` | 官方冻结模型预测，未启用该对照时无此目录 |
| `scored/` | 逐历元水平误差 |
| `config.json` / `status.json` | 实际参数、完成状态与冻结验证 |
| `data_inventory.json` / `cache_manifest.json` | 样本数量、输入及缓存校验信息 |
| `source/` / `archive_manifest.json` | 运行源码与所有结果文件哈希 |

`evaluation_set=heldout_tail` 表示同场次后 20%，`other_sessions` 表示其他场次。
`population=common_epochs` 用于同历元精度对比，`all_available` 分别统计各方法可用时刻。
查看当前模型 mean 时选择 `method=model` 或 `mean.csv` 中的 `model_mean_m`。

实现入口为 [evaluate_trained.py](evaluate_trained.py)，命令包装为 [test_model.sh](test_model.sh)。
训练命令与实现说明见 [TRAINING.md](TRAINING.md)。
